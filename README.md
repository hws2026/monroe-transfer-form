# Monroe County RP · WNY Transfer Form

A responsive HTML form for transfer terms, eligibility, notices, applicant acknowledgment, and administrative review.

## Preview

Open `index.html` in your browser. No installation or build is required.

Alternatively, run `python3 -m http.server 8000` in this directory and visit http://localhost:8000.

## Features

- Embedded CSS and JavaScript, with no external dependencies
- Responsive layout and section navigation
- 12 policy sections and an administrative review record
- 19 form fields
- Print / PDF styling
- Download completed entries as JSON

Entries are kept in the current page only. Download them before closing or reloading. No backend or online submission is configured.

## Editing

Edit `index.html` to update the text, CSS, or form behavior. The document remains marked **Draft — Pending Approval**.

## Hosting

The repository can be served by any static web host. For GitHub Pages, publish the repository's root from the `main` branch.
